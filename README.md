# DN_LANGGRAPH

คอร์สนี้สอนสร้างแอป LLM ด้วย LangChain และ LangGraph.js สำหรับคนที่เขียน TypeScript เป็นอยู่แล้ว ไม่ต้องเคยทำแอป LLM มาก่อน

แต่ละบทมี README อธิบาย ไฟล์ตัวอย่างให้รัน และแบบฝึกหัดที่มีเครื่องหมาย 👉 ให้เติมเอง คุณจะ **รันสคริปต์แล้วดูผลจริงจากโมเดล** ไม่มีชุดทดสอบอัตโนมัติมาตัดสินคำตอบ

ตลอดคอร์สเราสร้าง **ผู้ช่วยร้าน DN Shop** ที่ค้นสินค้า ตอบนโยบายร้านจากเอกสาร ดูคำสั่งซื้อ และขอคืนเงินโดยมีคนอนุมัติ ตอนจบคอร์สเต็มรูปแบบวางแผนไว้ 152 บท 21 ช่วง (บวกภาคผนวก)

> **สถานะ: กำลังจัดทำ** ตอนนี้ repo มี **ช่วงที่ 1 (บท 001–006)** และ **ช่วงที่ 2 (บท 007–016)** ช่วงที่ 3 เป็นต้นไปยังไม่มีในโฟลเดอร์ `lessons/` และจะทยอยเพิ่ม

เครื่องหมาย 🏫 ในสารบัญหมายถึงบทที่สอนในห้อง บทที่ไม่มี 🏫 ผู้เรียนอ่านและทำเองได้

## 1. ก่อนเริ่ม

สิ่งที่ต้องมีสำหรับช่วงที่ 1–2:

| สิ่งที่ต้องมี | ใช้ตั้งแต่บท | ค่าใช้จ่าย |
|---|---|---|
| Node.js 24 ขึ้นไป, pnpm 12, Git, VS Code | 002 | ฟรี |
| Ollama ในเครื่อง (ทางเลือก ต้องใช้เครื่อง RAM 16 GB ขึ้นไป) | 003 | ฟรี |
| บัญชี Ollama + เครดิตสำหรับ Ollama Cloud (ทำบท 003 หรือ 004 อย่างน้อย 1 บท ตามที่ผู้สอนบอกในรอบนั้น) | 004 | จ่ายตาม token ไม่มีโควต้าฟรี |
| บัญชี Google + API key จาก AI Studio | 005 | มีแผนฟรีที่จำกัดรายวัน หรือเปิด billing |

สิ่งที่ต้องมีของช่วงหลังๆ (LangSmith, Docker หรือ Postgres, hosting ฯลฯ) จะแจ้งในบทที่ต้องใช้

ข้อควรรู้:
- ทำบท 002–005 ให้เสร็จ **ก่อนเข้าห้อง** เพราะต้องสมัครบัญชี และถ้าใช้ Ollama ในเครื่องต้องโหลดโมเดลหลาย GB
- ทุกบทหลังจากนี้เรียกโมเดลจริง ถ้าเครื่องช้าหรือ RAM น้อย ให้ใช้ API (บท 004 และ 005) แทนการรันในเครื่อง
- แผนฟรีของ Gemini อาจเอาข้อมูลไปใช้เทรน ห้ามใส่ข้อมูลส่วนตัวในคำถาม (รายละเอียดในบท 005)
- **ห้าม commit ไฟล์ `.env` และห้ามแปะ API key ลงในโค้ดหรือแชท**

## 2. ติดตั้ง

ผู้สอนจะให้ลิงก์ GitHub ของโปรเจกต์ แทนที่ `ลิงก์ที่ผู้สอนให้` ด้วยลิงก์นั้นทั้งก้อน:

```bash
git clone ลิงก์ที่ผู้สอนให้ dn-langgraph
cd dn-langgraph
corepack enable
pnpm install
cp .env.example .env
```

บน Windows (PowerShell) ใช้คำสั่งเดียวกัน ยกเว้นบรรทัดสุดท้ายเป็น:

```powershell
Copy-Item .env.example .env
```

ผู้ใช้ Windows ต้องปลดล็อกการรันสคริปต์และตั้ง terminal ให้แสดงภาษาไทยได้ก่อน ขั้นตอนทั้งหมดอยู่ใน [บท 002](lessons/002-setup-project/README.md) ซึ่งอธิบายปัญหาที่พบบ่อยด้วย

เมื่อติดตั้งเสร็จ ตรวจว่าเครื่องพร้อมด้วย:

```bash
pnpm preflight
```

คำสั่งนี้ไม่เรียกโมเดลและไม่ใช้ token ถ้ามีอะไรขาด จะบอกเป็นภาษาไทยว่าต้องกลับไปดูบทไหน

## 3. ตั้งค่า provider

คอร์สใช้ API เป็นหลัก ผู้สอนจะบอกว่ารอบนั้นใช้ทางไหน:

| ทาง | บทที่อธิบาย | หมายเหตุ |
|---|---|---|
| Ollama ในเครื่อง | [003](lessons/003-setup-ollama-local/README.md) | ทางเลือก ต้องมี RAM 16 GB ขึ้นไป |
| Ollama Cloud | [004](lessons/004-setup-ollama-cloud/README.md) | ต้องมีบัญชีและเติมเครดิต |
| Google AI Studio (Gemini) | [005](lessons/005-setup-google/README.md) | ทุกคนต้องทำ มีแผนฟรี |

ชื่อโมเดลที่แนะนำและค่าที่ต้องใส่ใน `.env` อยู่ในบทเหล่านี้และไฟล์ `.env.example` ไม่ได้ระบุไว้ที่นี่ เพราะรุ่นโมเดลเปลี่ยนบ่อย

## 4. วิธีทำแบบฝึกหัด

1. อ่าน README ของบทในโฟลเดอร์ `lessons/NNN-ชื่อบท/`
2. รัน `example` ของบทก่อน เพื่อดูว่าผลหน้าตาเป็นอย่างไร
3. เปิดไฟล์ `exercise-N` แล้วหาบรรทัดที่มี **👉** แก้ตามที่คอมเมนต์บอก ไฟล์มีค่าชั่วคราวให้รันได้ตั้งแต่ยังไม่แก้ แต่ **ผลจะยังไม่ถูก** การรันได้ไม่ได้แปลว่าผ่าน
4. รันไฟล์ที่แก้แล้วเทียบกับหัวข้อ "ผลที่ควรเห็น" ใน README ของบท
5. ติดมากแล้วค่อยดูเฉลย (หัวข้อ 8)

ถ้ายังมี 👉 เหลืออยู่ ตอนรันจะมีคำเตือนบอกว่ายังเหลืออีกกี่จุด

ตั้งแต่บท 007 แบบฝึกที่ยังไม่เติมจะพิมพ์ 👉 บอกว่าต้องเติมอะไรแล้วหยุดทันที ไม่เรียกโมเดลและไม่เสีย token

## 5. วิธีรัน

| คำสั่ง | ทำอะไร |
|---|---|
| `pnpm preflight` | ตรวจ Node, pnpm, `.env` และ provider ที่ตั้งไว้ ไม่ใช้ token |
| `pnpm lesson 002` | รัน `example.ts` ของบท 002 |

| `pnpm lesson 016 example.ollama` | บทแชทบอทใน terminal พิมพ์ `จบ` เพื่อออก หรือกด Ctrl+D (Windows กด Ctrl+Z แล้ว Enter) |

คำสั่งเหมือนกันทั้ง macOS และ PowerShell คำสั่งอื่นจะเพิ่มในตารางนี้เมื่อถึงบทที่ใช้

## 6. วิธีอ่านผล

เนื่องจากโมเดลตอบไม่เหมือนเดิมทุกครั้ง ผลของแต่ละบทแบ่งเป็น 2 ขั้น:

- **ขั้นที่ 1 (กลไก):** ส่วนที่เป็นฟังก์ชันธรรมดา เช่น การประกอบคำขอหรืออ่าน response ผลต้อง **เหมือนที่ README บอกทุกตัวอักษร** ถ้าไม่ตรง แปลว่าโค้ดของคุณผิดที่ใดที่หนึ่ง
- **ขั้นที่ 2 (คำตอบจากโมเดล):** ผลไม่ตรงเป๊ะ ให้เทียบกับ **checklist** ใน README ของบท เช่น "มีข้อความตอบกลับ" หรือ "มีจำนวน token" ถ้าครบทุกข้อถือว่าผ่าน

**ทำไมคำตอบของคุณไม่เหมือนเฉลย:** โมเดลสุ่มคำตอบในแต่ละรอบ และต่างรุ่นต่าง provider ก็ตอบต่างกัน คำตอบในเฉลยเป็นแค่ตัวอย่างหนึ่ง ไม่ใช่คำตอบที่ถูกเพียงข้อเดียว ให้ดูว่าผ่าน checklist หรือไม่

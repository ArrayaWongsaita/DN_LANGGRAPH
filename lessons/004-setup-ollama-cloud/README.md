# บท 004: ใช้ Ollama Cloud (ทางเลือก)

> **ทำบท 003 หรือ 004 อย่างน้อย 1 บท ตามที่ผู้สอนบอกในรอบนั้น** บทนี้ใช้โมเดลที่รันบนเซิร์ฟเวอร์ของ Ollama เหมาะกับเครื่องที่ RAM น้อยหรือช้า (ถ้าทำบท 003 แล้วและเครื่องไหว ข้ามบทนี้ได้) ต้องมีบัญชีและเติมเครดิต

## จบบทนี้แล้วทำอะไรได้

- สมัครบัญชี Ollama และเข้าสู่ระบบด้วย `ollama signin`
- ใช้โมเดล `:cloud` ผ่านแอป Ollama ในเครื่อง
- สร้าง API key เพื่อยิงตรงไปที่ Ollama Cloud
- รู้ข้อจำกัดของ Cloud และดูราคา/ยอดเครดิตได้
- ตั้ง `.env` จน `pnpm preflight` แถว Ollama เป็น ✅

## เชื่อมกับที่รู้แล้ว

เหมือนเลือกว่าจะรัน backend เองหรือใช้บริการ cloud: บท 003 รันเอง บทนี้ใช้ของ Ollama ที่ host ให้ โค้ดของเราเรียกด้วยวิธีเดียวกัน (HTTP API ของ Ollama) ต่างกันแค่ที่อยู่ปลายทางและการส่ง key

## เนื้อหา

### 1. สมัครบัญชี

สมัครที่ [ollama.com](https://ollama.com) ก่อน

เรื่องค่าใช้จ่าย ผู้สอนเข้าใจว่า Cloud คิดเงินตามจำนวน token ที่ใช้ และไม่มีโควต้าฟรีสำหรับคอร์สนี้ ต้องเติมเครดิตก่อนจึงจะเรียกได้ **ข้อนี้เปลี่ยนได้ตามเวลาและยังรอผู้สอนตรวจกับบัญชีจริง** ให้ยึดข้อมูลล่าสุดจากหน้าทางการเสมอ: ราคาและแผนที่ [ollama.com/pricing](https://ollama.com/pricing) และรายละเอียด Cloud ที่ [docs.ollama.com/cloud](https://docs.ollama.com/cloud) การเติมเครดิตและดูยอดคงเหลือทำจากหน้าบัญชีหลังเข้าสู่ระบบ ถ้าหาปุ่มไม่เจอให้เริ่มจากหน้า pricing (ไม่ใส่ตัวเลขราคาในบทนี้ เพราะเปลี่ยนได้)

 Ollama ระบุว่าไม่เอาข้อมูลที่ส่งผ่าน Cloud ไปเทรนโมเดล

### 2. เลือกวิธีเชื่อมต่อ (2 วิธี เลือก 1 วิธี)

โมเดลที่คอร์สแนะนำบน Cloud: **TODO(6b): ใส่ชื่อโมเดล Cloud ที่เลือกจากการทดลอง (ทั้งรูปแบบ `ชื่อ:cloud` สำหรับวิธี ก และชื่อเปล่าสำหรับวิธี ข)**

**วิธี ก: `ollama signin` แล้วใช้ชื่อ `:cloud` (โค้ดยังชี้ไป localhost)**

ต้องติดตั้งแอป Ollama แล้ว (ขั้นตอนข้อ 1 ของบท 003 อย่างเดียว ไม่ต้องโหลดโมเดลใหญ่) แอปจะส่งต่อคำขอที่ใช้โมเดล `:cloud` ไปให้ Ollama Cloud

```bash
ollama signin
ollama pull <ชื่อโมเดล>:cloud
```

(`ollama pull` ของโมเดล `:cloud` โหลดแค่ข้อมูลอ้างอิงเล็กๆ ไม่ใช่ตัวโมเดล) แล้วตั้ง `.env`:

```
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=<ชื่อโมเดล>:cloud
```

**วิธี ข: ยิงตรงด้วย API key (ไม่ต้องติดตั้งแอป Ollama)**

1. เข้าเว็บ ollama.com ด้วยบัญชีของคุณ แล้วสร้าง API key ใหม่ในหน้าตั้งค่าบัญชี (ตำแหน่งเมนูอาจเปลี่ยน ดูวิธีสร้าง key ล่าสุดได้ที่ [docs.ollama.com/cloud](https://docs.ollama.com/cloud))
2. ใส่ใน `.env` (ชื่อโมเดลใช้แบบไม่มี `:cloud`):

```
OLLAMA_BASE_URL=https://ollama.com
OLLAMA_API_KEY=<key ของคุณ>
OLLAMA_MODEL=<ชื่อโมเดล>
```

เมื่อ `OLLAMA_BASE_URL` เป็น `https://ollama.com` โค้ดของคอร์สจะส่ง header `Authorization` พร้อม key ให้เอง

> ห้าม commit key และห้ามส่งให้ใคร ถ้าหลุด ให้ลบ key นั้นในหน้า Keys แล้วสร้างใหม่

### 3. ข้อจำกัดของ Ollama Cloud

- รับคำขอพร้อมกันได้ **3 request** ต่อบัญชี (ช่วงที่ 7 ที่เรียกโมเดลขนานกัน เราจะจำกัดให้ไม่เกินนี้)
- **ไม่รองรับ structured output แบบ JSON schema** (ช่วงที่ 3 ที่ให้โมเดลตอบเป็น object ที่มี type ต้องใช้ Google หรือ Ollama ในเครื่อง หรือวิธีสำรองที่บทนั้นจะสอน)
- **ไม่มีโมเดล embedding** (ช่วง RAG ให้ใช้ Google หรือ `ollama pull embeddinggemma` ในเครื่อง)

> **ยังไม่ได้ตรวจกับบัญชีจริง:** ขั้นตอนของวิธี ก (เปิดเบราว์เซอร์ตอน `ollama signin`, `ollama pull` ชื่อ `:cloud` โหลดแค่ข้อมูลอ้างอิง) และตำแหน่งหน้า API keys เขียนจากความเข้าใจของผู้สอน ถ้าไม่ตรงกับที่เห็น ให้ยึดเอกสารทางการแล้วแจ้งผู้สอน

## จุดที่มักพลาด

- **ลืมเติมเครดิต (หรือเครดิตหมด):** เรียกแล้วได้ error เรื่องสิทธิ์หรือเครดิต ดูยอดที่หน้าบัญชี
- **ใส่ `:cloud` ผิดวิธี:** วิธี ก ต้องมี `:cloud` ท้ายชื่อและชี้ localhost ส่วนวิธี ข ใช้ชื่อเปล่าและชี้ `https://ollama.com` ปนกันแล้วจะหาโมเดลไม่เจอ
- **วิธี ก แต่ลืมเปิดแอป Ollama:** `pnpm preflight` จะบอกว่าต่อ Ollama ไม่ได้
- **วิธี ข แต่ลืมใส่ `OLLAMA_API_KEY`:** `pnpm preflight` จะบอกว่ายังไม่ได้ตั้ง `OLLAMA_API_KEY`
- **key มีช่องว่างหรือขึ้นบรรทัดใหม่ติดมา:** วางใหม่ให้ติดกันบรรทัดเดียว
- **`OLLAMA_NUM_CTX=CHANGE_ME` ค้างใน `.env`:** ถ้าไม่ได้ทำบท 003 ให้ลบบรรทัดนี้หรือใส่เลขจริง (ดูบท 003) มิฉะนั้นโค้ดจะแจ้งว่าค่าไม่ถูกต้อง
- **ส่งข้อมูลส่วนตัวขึ้น Cloud:** ข้อมูลทั้งหมดออกจากเครื่องไปที่ Ollama อย่าใส่ข้อมูลที่ไม่อยากส่งออก

## วิธีรัน

บทนี้ไม่มีไฟล์โค้ด ทำใน terminal และเว็บ ollama.com ตามข้อ 1-2 แล้วตั้ง `.env` จากนั้นรัน:

```bash
pnpm preflight
```

คำสั่งเหมือนกันทั้ง macOS และ PowerShell

## ผลที่ควรเห็น

- [ ] สมัครบัญชีแล้ว เติมเครดิตแล้ว และรู้ว่าดูยอดคงเหลือที่ไหน
- [ ] (วิธี ก) `ollama signin` สำเร็จ และ `ollama list` เห็นชื่อ `:cloud`
- [ ] (วิธี ข) มี API key ใน `.env` และไม่ได้ commit
- [ ] `pnpm preflight` แถว Ollama เป็น ✅ เช่น `✅ Ollama (<ชื่อโมเดล>)`

## แบบฝึกหัด

1. เปิดหน้าราคาและหน้าบัญชี จดว่าเครดิตคงเหลือเท่าไรตอนเริ่ม และคุณจะรู้ได้อย่างไรว่าใกล้หมด
2. ลองแก้ `OLLAMA_MODEL` ให้พิมพ์ชื่อผิดหนึ่งตัวอักษร รัน `pnpm preflight` ดูข้อความที่ได้ แล้วแก้กลับ
3. เขียนสรุป 3 บรรทัดว่า ข้อจำกัด 3 ข้อของ Cloud กระทบงานแบบไหนในคอร์สนี้

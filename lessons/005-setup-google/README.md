# บท 005: สร้าง API key ของ Google AI Studio

บทนี้สร้าง API key สำหรับเรียกโมเดล Gemini และใส่ใน `.env` ใช้เวลาประมาณ 15 นาที ทุกคนต้องทำบทนี้

## จบบทนี้แล้วทำอะไรได้

- สร้าง API key ใน Google AI Studio
- ใส่ `GOOGLE_API_KEY` และ `GOOGLE_MODEL` ใน `.env`
- ดูหน้า rate limit และเข้าใจเวลารีเซ็ต
- รู้ความเสี่ยงของแผนฟรีเรื่องข้อมูล และไม่ commit key
- `pnpm preflight` แถว Google เป็น ✅

## เชื่อมกับที่รู้แล้ว

API key ของ Google ก็เหมือน key ของ API อื่นที่คุณเคยใช้ (เช่น Maps หรือ Stripe) ใส่ใน `.env` อ่านผ่าน `src/lib/env.ts` ที่เรียนในบท 002 และห้ามใส่ในโค้ด

## เนื้อหา

### 1. สร้าง API key

1. เปิด [aistudio.google.com/apikey](https://aistudio.google.com/apikey) ด้วยบัญชี Google
2. กด Create API key (ถ้าให้เลือกโปรเจกต์ ให้สร้างโปรเจกต์ใหม่หรือเลือกอันที่ใช้กับคอร์สนี้)
3. คัดลอก key ที่ได้ (ขึ้นต้นด้วย `AIza`)

### 2. ใส่ใน `.env`

เปิด `.env` ใน VS Code (ไม่ใช่ Notepad เพราะเสี่ยง BOM ดูบท 002) แก้ 2 บรรทัด:

```
GOOGLE_API_KEY=<key ที่คัดลอกมา>
GOOGLE_MODEL=<ชื่อโมเดล>
```

โมเดลที่คอร์สแนะนำ: **TODO(6b): ใส่ชื่อโมเดล Google ที่เลือกจากการทดลอง (ให้ตรงกับ `GOOGLE_MODEL` ใน `.env.example`)** ใส่ชื่อโมเดลแบบไม่มีคำนำหน้า `models/` เขียนแบบไม่มีเครื่องหมายคำพูดและไม่มีช่องว่างรอบ `=`

### 3. ดูหน้า rate limit

ใน AI Studio เปิดหน้า usage/rate limit (หน้าตาอาจเปลี่ยนตามเวลา ดูในเมนูของโปรเจกต์) จะเห็นโควต้าของโมเดลแต่ละตัว สิ่งที่ต้องรู้:

- **ลิมิตนับต่อโปรเจกต์** ไม่ใช่ต่อ key: หลาย key ในโปรเจกต์เดียวกันใช้โควต้าร่วมกัน
- **รีเซ็ตราวบ่าย 3 โมงเวลาไทย** (เที่ยงคืนเวลาแปซิฟิก) ช่วง daylight saving ของสหรัฐฯ จะเป็นบ่าย 2 โมง
- **แผนฟรีมีลิมิตรายวัน** ถ้าชนบ่อยจนทำบทไม่ทัน ให้ทำอย่างใดอย่างหนึ่ง: เปิด billing ในโปรเจกต์ หรือสลับไปใช้ Ollama (บท 003-004)

### 4. ความปลอดภัย

- **ข้อมูลในแผนฟรีอาจถูกนำไปเทรนโมเดล:** ห้ามใส่ข้อมูลส่วนตัวของตัวเองหรือของคนอื่น (ชื่อจริง เบอร์โทร ที่อยู่ ข้อมูลที่ทำงาน) ลงใน prompt ข้อมูลของ DN Shop ในคอร์สเป็นข้อมูลสมมติทั้งหมด จึงใช้ได้
- **ห้าม commit key:** `.env` ถูกกันไว้ใน `.gitignore` แล้ว อย่าคัดลอก key ไปไว้ในไฟล์อื่นที่ commit (รวมถึง `.env.example`) อย่าแคปหน้าจอที่เห็น key แล้วส่งต่อ
- ถ้า key หลุด ให้ลบในหน้า API keys ของ AI Studio แล้วสร้างใหม่ทันที

## จุดที่มักพลาด

- **คัดลอก key ไม่ครบหรือมีช่องว่างติดมา:** `pnpm preflight` จะบอกว่า "key ไม่ถูกต้อง"
- **ใส่ชื่อโมเดลผิด:** `pnpm preflight` จะบอกว่า "ไม่พบโมเดล ... ในบัญชีนี้ ตรวจ GOOGLE_MODEL" ตรวจตัวสะกดและอย่าใส่ `models/` นำหน้า
- **บันทึก `.env` ด้วย Notepad แบบมี BOM:** ดูบท 002
- **ชนลิมิตรายวัน:** error 429 หรือข้อความ quota ให้รอรีเซ็ต เปิด billing หรือใช้ Ollama
- **ใช้ key ในโปรเจกต์ที่ไม่ได้เปิด Generative Language API:** ปกติ AI Studio เปิดให้เอง ถ้าไม่ได้ ให้สร้าง key ใหม่จากหน้า AI Studio

## วิธีรัน

บทนี้ไม่มีไฟล์โค้ด ทำบนเว็บ AI Studio และแก้ `.env` ตามข้อ 1-2 จากนั้นรัน:

```bash
pnpm preflight
```

คำสั่งเหมือนกันทั้ง macOS และ PowerShell

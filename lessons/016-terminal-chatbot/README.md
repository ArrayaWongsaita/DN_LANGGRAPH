# บท 016 ⭐: แชทบอทร้าน DN Shop ตัวแรกใน terminal

บทผลงานของช่วงที่ 2: เอาสิ่งที่เรียนมาทั้งช่วง (เรียกโมเดล, ข้อความ 3 บทบาท, stream) มาประกอบเป็นแชทบอทร้าน DN Shop ที่คุยกับเราใน terminal ได้หลายรอบ และจำได้ว่าเราเคยพูดอะไร ก่อนอื่นต้องเข้าใจก่อนว่า **โมเดลจำอะไรไม่ได้เลย** แล้วแชทบอทจำได้อย่างไร ใช้เวลาประมาณ 60-90 นาที ทำทั้งแบบ Ollama (`.ollama.ts`) และ Google (`.google.ts`)

## จบบทนี้แล้วทำอะไรได้

- อธิบายได้ว่าทำไมโมเดลจำบทสนทนาไม่ได้เอง และแชทบอทแก้ด้วยการส่งประวัติไปทุกครั้ง
- เขียน loop ถาม-ตอบใน terminal ด้วย `ask()` เก็บประวัติเป็น `history` และออกเมื่อพิมพ์ `จบ` หรือ input หมด
- แสดงคำตอบทีละส่วนด้วย stream แล้วเก็บข้อความเต็มลงประวัติ
- เพิ่มคำสั่งพิเศษ (`/ล้าง`) ให้แชทบอท
- ตัดประวัติให้สั้นลงก่อนส่งเพื่อประหยัด token
- รวมชิ้นของ stream เพื่ออ่านจำนวน token ของแต่ละตา

### 1. โมเดลจำอะไรไม่ได้ ต้องส่งประวัติไปทุกครั้ง

ลองคิดว่าเราถามโมเดล 2 ครั้ง:

1. `ฉันชื่อสมชาย` โมเดลตอบว่ายินดีที่ได้รู้จัก
2. `ฉันชื่ออะไร` ถ้าส่งแค่ประโยคนี้ไป โมเดลไม่เคยเห็นครั้งที่ 1 เลย จึงตอบไม่ได้

ทุกการเรียกโมเดลแยกขาดจากกัน สิ่งเดียวที่โมเดลรู้คือข้อความที่เราส่งไปในครั้งนั้น แชทบอทที่ "จำได้" จึงไม่ได้ใช้เวทมนตร์ แค่เก็บทุกข้อความของทั้งสองฝ่ายไว้ในอาร์เรย์ แล้ว **ส่งทั้งอาร์เรย์ไปทุกครั้ง**

ขั้นที่ 1 ของไฟล์ตัวอย่างทดลองเรื่องนี้ด้วยโมเดลปลอม `fakeModel` ที่ทำตัวเหมือนโมเดลจริงในข้อนี้: รู้เฉพาะสิ่งที่อยู่ใน `messages` ที่ส่งมา ไม่ยิงเน็ต ผลเหมือนกันทุกครั้ง:

- ส่ง `[human("ฉันชื่ออะไร")]` ได้ `ไม่ทราบชื่อครับ`
- ส่ง `[human("ฉันชื่อสมชาย"), ai("ยินดีที่ได้รู้จักครับ"), human("ฉันชื่ออะไร")]` ได้ `คุณชื่อสมชายครับ`

(`fakeModel` ค้นชื่อจากข้อความ **ก่อน** ข้อความสุดท้ายเท่านั้น เพราะข้อความสุดท้ายคือคำถามปัจจุบัน ถ้านับด้วย `ฉันชื่ออะไร` จะถูกอ่านเป็นชื่อ "อะไร")

**ราคาของการจำ:** ประวัติยาวขึ้นทุกตา ดังนั้น token ขาเข้า (ที่เสียเงินหรือเสียโควต้า) ก็เพิ่มทุกตา และถ้ายาวเกินหน้าต่างบริบทของโมเดลก็ส่งไม่ได้ แบบฝึกข้อ 2 ลองตัดประวัติ ส่วนวิธีที่ฉลาดกว่านี้ (สรุปบทสนทนาเก่า) จะเรียนในบทหลังๆ

### 2. `ask()` ของ `src/lib/ask.ts`

```ts
import { ask } from "../../src/lib/ask";
const line = await ask("คุณ: ");
```

- `ask(prompt)` พิมพ์ `prompt` แล้วรอผู้ใช้พิมพ์ 1 บรรทัดจน Enter คืนข้อความที่พิมพ์ (ตัดช่องว่างหัวท้ายแล้ว)
- คืน `null` เมื่อ input หมด (EOF) เช่นกด Ctrl+D หรือมีคน pipe ข้อความมาแล้วหมด ต้องเช็ก `null` เสมอ ไม่เช่นนั้นโปรแกรมจะวนถามไม่รู้จบ
- ทำงานได้ทั้งตอนเราพิมพ์เองและตอนอ่านจาก pipe (`pnpm verify` ใช้วิธีนี้ส่งข้อความทดสอบเข้ามา)

**ระวังชื่อซ้ำ:** `ask()` ในบทนี้ **ถามคน** (รับข้อความจาก terminal) ส่วน `ask()` ที่เขียนในแบบฝึกข้อ 3 ของบท 006 **ถาม LLM** (ส่งคำถามไปโมเดล) เป็นคนละฟังก์ชัน แค่ชื่อเหมือนกัน

### 3. loop ของแชทบอท

```ts
const history: BaseMessage[] = [new SystemMessage(SYSTEM)];
while (true) {
  const line = await ask("คุณ: ");
  if (line === null || line === "จบ") break;   // input หมด หรือผู้ใช้พิมพ์ จบ
  if (line === "") continue;                    // กด Enter เปล่า ถามใหม่
  history.push(new HumanMessage(line));
  // ... stream คำตอบจาก model.stream(history) ...
  history.push(new AIMessage(reply));
}
```

ทีละส่วน:

- `history` เริ่มด้วย system message ที่บอกบทบาท (ผู้ช่วยร้าน DN Shop ตอบไทย สั้น สุภาพ) system อยู่ตัวแรกเสมอ
- `line === null || line === "จบ"`: ออกจาก loop `null` คือ input หมด ถือว่าจบเหมือนพิมพ์ `จบ`
- `line === ""`: กด Enter โดยไม่พิมพ์อะไร ไม่ส่งข้อความว่างให้โมเดล (บาง provider เช่น Gemini ไม่รับข้อความว่าง) แล้วถามใหม่ ไม่นับเป็น 1 ตา
- ถ้าเป็นข้อความปกติ: push `HumanMessage` ก่อนเรียกโมเดล เพื่อให้ประวัติที่ส่งมีคำถามล่าสุดอยู่ท้ายสุด
- พิมพ์ `ผู้ช่วย: ` แล้วพิมพ์ทุกชิ้นของ `model.stream(history)` ทันที (ด้วย `process.stdout.write` เหมือนบท 015) พร้อมต่อข้อความเต็มไว้ในตัวแปร `reply`
- จบคำตอบแล้ว push `new AIMessage(reply)` เก็บคำตอบเต็ม ตาหน้าโมเดลจะได้เห็นว่าตัวเองเคยตอบอะไร

ตอนจบพิมพ์ `ลาก่อนครับ` และ `จำนวนข้อความในประวัติ: N` (system 1 + ทุกคำถามและคำตอบ)

### 4. วิธีออกจากแชท

| วิธี | ผล |
|---|---|
| พิมพ์ `จบ` แล้ว Enter | ใช้ได้ทุกระบบ เป็นวิธีหลักที่แนะนำ |
| กด Ctrl+D (macOS) | บอก terminal ว่า input หมด `ask()` คืน `null` โปรแกรมจบเอง |
| กด Ctrl+Z แล้วกด Enter (Windows PowerShell) | เทียบเท่า Ctrl+D ของ macOS **Ctrl+D ใน PowerShell ไม่ได้ทำให้ input จบ** |
| กด Ctrl+C | หยุดโปรแกรมทันทีทุกระบบ (ประวัติที่คุยมาหายหมด และไม่พิมพ์ `ลาก่อนครับ`) |

ผู้ใช้ Windows ไม่ต้องจำเรื่อง Ctrl+Z ถ้าพิมพ์ `จบ` เป็นนิสัย

### 5. ภาษาไทยใน terminal

- ถ้าพิมพ์ไทยแล้วเพี้ยนหรือเป็น `?` ให้กลับไปดูการตั้ง terminal ในบท 002
- ถ้ามีคน pipe ข้อความไทยเข้าโปรแกรมจาก **Windows PowerShell 5.1** (เช่น `"สวัสดี" | pnpm lesson 016 example.ollama`) ข้อความอาจเพี้ยน เพราะ PowerShell 5.1 ส่งข้อความออกด้วย encoding ที่ตั้งด้วย `$OutputEncoding` (ตั้งเป็น UTF-8 ตามบท 002 แล้วลองใหม่) การ **พิมพ์เองใน terminal ไม่มีปัญหานี้** ตอนเรียนให้พิมพ์เอง

### 6. ขั้นที่ 2: ลองใช้จริง

รัน `pnpm lesson 016 example.ollama` แล้วคุยจริง: ลองบอกชื่อตัวเอง ถามกลับว่า "ฉันชื่ออะไร" กด Enter เปล่าๆ 1 ครั้ง (ต้องถามใหม่ ไม่ส่งไปโมเดล) พิมพ์ผิดแล้วลบด้วย Backspace แล้วพิมพ์ `จบ`

## จุดที่มักพลาด

- **ลืม push คำตอบของผู้ช่วยลงประวัติ:** โมเดลจะเห็นแต่คำถามของเรา ไม่เห็นว่าตัวเองเคยตอบอะไร คุยต่อได้แปลกๆ
- **ลืมเช็ก `null` จาก `ask()`:** ถ้าเช็กแค่ `"จบ"` แล้ว input หมดกลางทาง จะวนไม่รู้จบ
- **ส่งข้อความว่างให้โมเดล:** บาง provider ตอบ error ต้องเช็ก `line === ""` ก่อนเสมอ
- **push `HumanMessage` หลังเรียกโมเดล:** โมเดลจะไม่เห็นคำถามล่าสุด ต้อง push ก่อน `model.stream(history)`
- **สร้าง `history` ใหม่ในทุกรอบของ loop:** ประวัติหายทุกตา ต้องสร้างครั้งเดียวนอก loop
- **คิดว่าต้นทุนคงที่ทุกตา:** token ขาเข้าเพิ่มขึ้นทุกตาเพราะส่งประวัติทั้งหมด (แบบฝึกข้อ 3 ให้เห็นกับตา)
- **ตัดประวัติแล้วลบ system ทิ้ง:** system ต้องอยู่ตัวแรกเสมอ ไม่นับเป็นข้อความที่ตัดได้
- **กด Ctrl+D บน Windows แล้วไม่จบ:** ต้องเป็น Ctrl+Z แล้ว Enter หรือพิมพ์ `จบ`

## แบบฝึกหัด

1. **`exercise-1.*`:** เติม `handleCommand(line, history)` ให้ถ้า `line` คือ `/ล้าง` เหลือแค่ system ใน `history` (แก้อาร์เรย์เดิม) แล้วคืน `true` ถ้าไม่ใช่คำสั่งคืน `false` ไฟล์จะพิมพ์ `ล้างประวัติแล้ว` เมื่อได้ `true` และถามต่อโดยไม่ส่งอะไรให้โมเดล
2. **`exercise-2.*`:** เติม `trimHistory(history, max)` ให้คืนอาร์เรย์ใหม่ที่เป็น system ตามด้วย `max` ข้อความล่าสุด ถ้าข้อความแรกที่เหลือเป็นคำตอบของผู้ช่วย ให้ตัดทิ้ง (provider อย่าง Gemini ไม่รับประวัติที่ขึ้นต้นด้วยคำตอบของผู้ช่วย) ไฟล์ส่งเฉพาะผลนี้ไปโมเดล แต่เก็บ `history` ครบ และพิมพ์ `(ส่งไป N ข้อความ)` ก่อนคำตอบทุกตา (ใช้ `max` เท่ากับ 4)
3. **`exercise-3.*`:** เติม `mergeChunks(chunks)` ให้รวม `AIMessageChunk` ทุกชิ้นของคำตอบด้วย `concat` แล้วคืนชิ้นที่รวมแล้ว (ไม่มีชิ้นเลยคืน `undefined`) ไฟล์จะอ่าน `usage_metadata` ของชิ้นที่รวมแล้ว และพิมพ์ `(token ขาเข้า N ขาออก M)` หลังคำตอบทุกตา

ไฟล์แบบฝึกมี 👉 และค่าชั่วคราวไว้ให้รันได้ แต่ผลจะยังไม่ผ่าน checklist จนกว่าจะแก้ครบ ถ้าติด เปิดไฟล์ `example.*` ข้างๆ และอ่านเฉลยบน branch `solutions` เมื่อทำเองแล้ว

# บท 003: ติดตั้ง Ollama ในเครื่อง (ทางเลือก)

> **ทำบท 003 หรือ 004 อย่างน้อย 1 บท ตามที่ผู้สอนบอกในรอบนั้น** บทนี้รันโมเดลบนเครื่องคุณเอง ใช้ได้เมื่อเครื่องมี RAM 16 GB ขึ้นไป **ถ้าเครื่องช้าหรือ RAM น้อย ให้ข้ามไปทำบท 004 (Ollama Cloud) แทน** เพราะทุกบทต่อจากนี้เรียกโมเดลจริง เครื่องที่ช้าจะรอนานมาก

## จบบทนี้แล้วทำอะไรได้

- ติดตั้ง Ollama และดาวน์โหลดโมเดลมาไว้ในเครื่อง
- คุยกับโมเดลใน terminal ด้วย `ollama run` (ลองภาษาไทย)
- ดูว่าโมเดลอะไรโหลดอยู่ด้วย `ollama ps`
- เลือกขนาดโมเดลให้เหมาะกับ RAM ของเครื่อง
- ขยาย context length ให้พอสำหรับ agent
- ตั้ง `OLLAMA_BASE_URL`, `OLLAMA_MODEL`, `OLLAMA_NUM_CTX` ใน `.env` จน `pnpm preflight` แถว Ollama เป็น ✅

## เชื่อมกับที่รู้แล้ว

Ollama เหมือน "server ของโมเดล" ที่รันบนเครื่องคุณ มันเปิด HTTP API ที่ `http://localhost:11434` เหมือนที่คุณเคยรัน backend ในเครื่องตอนพัฒนา โค้ดของเราเรียก URL นี้ด้วย `fetch` (บท 006) หรือผ่าน LangChain (ช่วงที่ 2) ได้เลย ต่างจากเรียก API ของ Google ตรงที่ไม่ต้องใช้ key และข้อมูลไม่ออกจากเครื่อง

## เนื้อหา

### 1. ติดตั้ง Ollama

ดาวน์โหลดตัวติดตั้งจาก [ollama.com/download](https://ollama.com/download) (มี macOS และ Windows) ติดตั้งแล้วเปิดแอป Ollama ค้างไว้ (จะเห็นไอคอนที่ menu bar หรือ system tray)

ตรวจว่าใช้ได้:

```bash
ollama --version
```

### 3. ดาวน์โหลดโมเดลและลองคุย

โมเดลมีขนาดหลาย GB ควรโหลดตอนมี Wi-Fi ที่เร็วและทำก่อนเข้าห้องเรียน แทนที่ `<ชื่อโมเดล>` ด้วยชื่อที่ได้จากข้อ 2:

```bash
ollama pull <ชื่อโมเดล>
ollama run <ชื่อโมเดล>
```

เมื่อขึ้นเครื่องหมาย `>>>` ลองพิมพ์ภาษาไทย เช่น `ร้านค้าออนไลน์คืออะไร ตอบสั้นๆ` ออกจากโหมดคุยด้วย `/bye`

คำสั่งทั้งหมดเหมือนกันทั้ง macOS และ PowerShell

### 4. ดูโมเดลที่โหลดอยู่ด้วย `ollama ps`

```bash
ollama ps
```

แสดงโมเดลที่อยู่ในหน่วยความจำตอนนี้ ขนาด และส่วนที่ใช้ GPU/CPU ถ้าคอลัมน์ `PROCESSOR` มี CPU ปนอยู่มาก แปลว่าโมเดลใหญ่เกินกว่า VRAM จะรับ จะช้าลง ให้ลองรุ่นเล็กลง

### 5. ขยาย context length

ค่าเริ่มต้นของ context ใน Ollama เล็กมาก (ประมาณ 4,000 token บนเครื่องที่ VRAM ไม่ถึง 24 GB) แต่ agent ต้องเก็บ prompt, ประวัติ และผลของ tool ไว้ด้วย เอกสารของ Ollama แนะนำให้ใช้อย่างน้อย 64,000 token สำหรับ agent

**ข้อแลกเปลี่ยน:** context ยิ่งยาวยิ่งใช้ RAM เพิ่ม ต้องบาลานซ์กับขนาดโมเดล (ตารางข้อ 2)

มี 2 ที่ที่ต้องตั้ง:

1. **ที่ Ollama (สำหรับ `ollama run` ที่คุยด้วยมือ):** เปิดแอป Ollama → Settings → ปรับ slider "Context length" หรือตั้งตัวแปรสภาพแวดล้อม `OLLAMA_CONTEXT_LENGTH` แล้วเปิด Ollama ใหม่

   macOS:

   ```bash
   launchctl setenv OLLAMA_CONTEXT_LENGTH 32768
   ```

   PowerShell:

   ```powershell
   setx OLLAMA_CONTEXT_LENGTH 32768
   ```

   (ตัวเลข 32768 เป็นแค่ตัวอย่างของวิธีตั้ง ใช้ค่าตามข้อ 6)

2. **ที่โค้ดของเรา:** ใส่ `OLLAMA_NUM_CTX` ใน `.env` (ข้อ 6) โค้ดของคอร์สจะส่งค่านี้ให้ Ollama ทุกครั้งที่เรียก

ค่า context ที่คอร์สแนะนำ: **TODO(6b): ใส่ค่า OLLAMA_NUM_CTX ที่วัดแล้วว่าเหมาะ (RAM ที่ใช้เพิ่มเท่าไร)**

### 6. ตั้งค่าใน `.env`

เปิด `.env` ใน VS Code แล้วแก้ 3 บรรทัดนี้ (แทนค่าตามข้อ 2 และข้อ 5):

```
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=<ชื่อโมเดล>
OLLAMA_NUM_CTX=<ค่า context>
```

### 7. (ไม่บังคับ) โมเดล embedding

ช่วง RAG (ช่วงที่ 12) ต้องใช้โมเดลแปลงข้อความเป็นเวกเตอร์ ถ้าอยากใช้แบบในเครื่อง โหลดไว้ก่อนได้:

```bash
ollama pull embeddinggemma
```

ถ้าไม่โหลดตอนนี้ ไม่เป็นไร ไปโหลดตอนถึงบทนั้น

## จุดที่มักพลาด

- **ลืมเปิดแอป Ollama:** `pnpm preflight` จะบอกว่า "ต่อ Ollama ไม่ได้ เปิดโปรแกรม Ollama ก่อน" เปิดแอปแล้วลองใหม่
- **ชื่อโมเดลใน `.env` ไม่ตรงกับที่โหลด:** ต้องตรงทุกตัวอักษรรวมส่วนหลัง `:` (เช่น tag ของขนาด) ดูชื่อที่มีจริงด้วย `ollama list`
- **เลือกโมเดลใหญ่เกิน RAM:** เครื่องค้างหรือตอบช้ามาก ดู `ollama ps` ถ้า CPU เยอะให้ลดขนาด
- **ตั้ง context ที่เดียว:** ตั้งที่แอป Ollama แล้วลืมใส่ `OLLAMA_NUM_CTX` ใน `.env` (หรือกลับกัน) ให้ตั้งทั้งสองที่
- **เปลี่ยนตัวแปรสภาพแวดล้อมแล้วไม่ได้เปิด Ollama ใหม่:** ค่าใหม่ไม่มีผลจนกว่าจะปิดแล้วเปิดแอปอีกครั้ง
- **ใช้ `OLLAMA_BASE_URL` ที่มี `/` ท้ายหรือไม่มี `http://`:** โค้ดตัด `/` ท้ายให้ แต่ต้องขึ้นต้นด้วย `http://` เสมอ

## วิธีรัน

บทนี้ไม่มีไฟล์โค้ด ทำใน terminal ตามข้อ 3-4 แล้วตั้ง `.env` ตามข้อ 6 จากนั้นรัน:

```bash
pnpm preflight
```

## ผลที่ควรเห็น

- [ ] `ollama --version` แสดงเลขเวอร์ชัน
- [ ] `ollama run` คุยภาษาไทยได้ ตอบกลับเป็นภาษาไทยที่อ่านรู้เรื่อง
- [ ] `ollama ps` เห็นโมเดลที่โหลดอยู่
- [ ] `pnpm preflight` แถว Ollama เป็น ✅ และแสดงชื่อโมเดลในวงเล็บ เช่น `✅ Ollama (<ชื่อโมเดล>)`

ถ้ายังเป็น ❌ ข้อความหลังเครื่องหมาย — จะบอกสาเหตุ (ต่อไม่ได้, ยังไม่มีโมเดล, ฯลฯ) แก้ตามนั้นแล้วรันใหม่

## แบบฝึกหัด

1. ลองถามโมเดลในเครื่องด้วยคำถามภาษาไทย 3 คำถามใน `ollama run` จดว่าตอบเร็วหรือช้า คำตอบอ่านรู้เรื่องไหม
2. เปิด `ollama ps` ระหว่างที่โมเดลกำลังตอบ ดูว่า `PROCESSOR` ใช้ GPU เต็มหรือแบ่งกับ CPU
3. ลองลดหรือเพิ่ม `OLLAMA_NUM_CTX` แล้วดู RAM ที่ใช้ (Activity Monitor บน macOS หรือ Task Manager บน Windows) เปลี่ยนไปเท่าไร

# DN_LANGGRAPH — เอกสารออกแบบคอร์สและ repo

> สถานะ: อนุมัติแล้ว · 2026-11-15
> เอกสารคู่กัน: [ลำดับบทเรียน](2026-11-15-dn-langgraph-outline-draft.md) เป็นส่วนหนึ่งของเอกสารนี้ บอกเนื้อหาของทั้ง 152 บท 21 ช่วง ภาคผนวก 3 บท และหลักการจัดลำดับ 13 ข้อ ส่วนเอกสารนี้บอกว่า repo จัดอย่างไรและแต่ละส่วนทำงานอย่างไร
> คำว่า **(ผู้ออกแบบเลือก)** = เรื่องที่ผู้ใช้ไม่ได้สั่งไว้ ผู้ออกแบบตัดสินเองพร้อมเหตุผล ผู้ใช้แก้ได้

## 1. เป้าหมายและเหตุผล

ผู้ใช้สอนคอร์ส DN_PLAYWRIGHT (https://github.com/ArrayaWongsaita/DN_PLAYWRIGHT) อยู่แล้ว และอยากทำคอร์ส LangGraph รูปแบบเดียวกันให้ผู้เรียนที่เขียน TypeScript เป็นแต่ยังไม่เคยทำแอป LLM สิ่งที่ผู้ใช้ต้องการ:

- แยกเนื้อหาเป็นเรื่องย่อยที่สุด เรียงทีละขั้นไม่ข้าม ให้ผู้เรียนทำได้ทีละเรื่องแล้วมั่นใจขึ้นเรื่อยๆ
- ใช้ Ollama (ในเครื่อง และ Ollama Cloud) กับ Google AI · ช่วงแรกฝึกทั้ง 2 แบบ แล้วผู้เรียนเลือกเองตามประสบการณ์และลิมิต API ของตัวเอง
- **ผู้เรียนใช้ API เป็นหลัก** (Google AI และ Ollama Cloud) · Ollama ในเครื่องเป็นทางเลือกสำหรับคนที่เครื่องไหว · รอบสอนไหนจะใช้ Ollama Cloud ขึ้นกับช่วงเวลาที่สอนและ API ที่คุ้มค่าตอนนั้น
- **ปล่อย repo ครั้งเดียว** เมื่อครบทุกบท พร้อม branch `solutions`
- ครอบคลุม LangGraph ทั้งหมด ไม่จำกัดจำนวนบท
- ผู้เรียน **รันสคริปต์แล้วเห็นผลจริงจากโมเดล** ไม่ต้องคุมจำนวน token · ถ้าโควต้าฟรีไม่พอผู้เรียนเติมเงินเอง · ไม่มี test อัตโนมัติตรวจคำตอบของผู้เรียน

## 2. เป้าหมาย สิ่งที่ไม่ทำ และสิ่งที่ถือว่าล้มเหลว

**เป้าหมาย**
- 152 บท + ภาคผนวก 3 บท ตามเอกสารลำดับบทเรียน ทุกบทรันได้ด้วยคำสั่งเดียว
- ผู้เรียนเรียนต่อเองได้หลังจบส่วนที่สอนในห้อง โดยอ่าน README ของบทอย่างเดียว
- ใช้ได้เหมือนกันทั้ง macOS และ Windows PowerShell
- บทปิดท้าย (152) ได้ผู้ช่วย DN Shop ที่ deploy ขึ้นเว็บได้จริง
- ทุกบทใช้ได้ครบทั้งกับ Google และ Ollama Cloud ผู้สอนจึงเลือก API ที่คุ้มค่าที่สุดในแต่ละรอบสอนได้โดยไม่ต้องแก้บท
- ปล่อย `main` และ `solutions` พร้อมกันครั้งเดียว (ข้อ 5.14)

**ไม่ทำ**
- ไม่มีระบบตรวจคำตอบของผู้เรียนอัตโนมัติ
- ไม่สอน Python (บท 060 สอนแค่อ่านโค้ด Python ที่เจอบนเน็ต)
- ไม่ deploy ผ่าน LangSmith Cloud (ต้องจ่าย $39 ต่อคนต่อเดือน)
- provider หลักมีแค่ Ollama กับ Google · เจ้าอื่นอยู่ภาคผนวก A
- ไม่มีฐานข้อมูลจริงของร้าน ข้อมูลอยู่ในหน่วยความจำ ยกเว้นบทที่สอน SQLite และ Postgres

**ถือว่าล้มเหลว แม้โค้ดจะรันได้**
- มีบทที่ใช้สิ่งที่ยังไม่ได้สอน หรือกระโดดข้ามขั้น
- บทที่ควรเรียกโมเดลจริงกลับแสดงผลปลอม (ยกเว้น 4 บทที่ตั้งใจ: 002, 134–136)
- ชื่อโมเดลฝังอยู่ในโค้ด แล้วบทพังเมื่อ provider ถอดรุ่นนั้น
- checklist ใน README ไม่ผ่านกับ Google หรือ Ollama Cloud ในการรันตามปกติ (Ollama ในเครื่องใช้เกณฑ์ในข้อ 5.10)
- API key หลุดลง git หรือไปอยู่ฝั่ง browser
- ตัวช่วยกลางยาวหรือซับซ้อนจนผู้เรียนเปิดอ่านแล้วไม่เข้าใจ

## 3. ข้อจำกัด

- **เวอร์ชันที่ตรวจไว้:** `@langchain/langgraph` 1.7.4, `@langchain/core` 1.4.1, `langchain` 1.6.6, `@langchain/ollama` 1.3.0, `@langchain/google` 0.2.15
- **เครื่องมือ:** Node 24 ขึ้นไป, pnpm 12, TypeScript ~6.0, Next.js ~16.4, React ~19.3 ใช้รุ่นเดียวกับ DN_PLAYWRIGHT
- **Provider:**
  - Gemini แผนฟรีจำกัดต่อโปรเจกต์ต่อวัน · รุ่นใหม่เลิกใช้ `temperature`
  - Ollama Cloud ไม่มีแผนฟรี รับพร้อมกัน 3 request ไม่รองรับ structured output แบบ JSON schema และไม่มีโมเดล embedding
  - Ollama ในเครื่องใช้ context 4k เป็นค่าเริ่มต้นบนเครื่องที่ VRAM ไม่ถึง 24 GB · `ChatOllama` ไม่รองรับ `tool_choice`
- **Studio:** `npx @langchain/langgraph-cli dev` ต้องมี LangSmith API key (สมัครฟรี)
- **Deploy:** server บน cloud เรียก Ollama ในเครื่องผู้เรียนไม่ได้ และบน serverless ใช้ `MemorySaver` กับ SQLite ไม่ได้
- **ภาษา:** README, ข้อความที่สคริปต์พิมพ์ และคอมเมนต์ในโค้ดของบทเป็นภาษาไทยแบบ DN_PLAYWRIGHT · ชื่อตัวแปร ฟังก์ชัน และไฟล์เป็นภาษาอังกฤษ

## 7. ต้องลองก่อนสร้างจริง

รวมรายการ "สิ่งที่ต้องทดสอบจริงตอนสร้างคอร์ส" ในเอกสารลำดับบทเรียน กับเรื่องจากเอกสารนี้:

- **MCP:** MCP server แบบ stdio เปิดผ่าน tsx ได้ทั้ง macOS และ Windows
- **`--env-file`:** รันผ่าน tsx แล้วใช้ได้บน Windows PowerShell
- **pnpm:** `pnpm install` ไม่ขึ้นข้อความ "Ignored build scripts" หลังตั้ง `allowBuilds`

## ผลทดลองที่แผนนี้ใช้ (2026-11-16, แพ็กเกจรุ่นที่ล็อก)

ทดลองกับ server ปลอมในเครื่อง และยิง opencode จริง 3 ครั้ง (ไม่พิมพ์ key):

| เรื่อง | ผลที่เห็น | ผลต่อแผน |
|---|---|---|
| `ChatOllama` ส่งคำขอ | ส่ง `stream: true` เสมอ แม้เรียก `invoke` · ส่ง `think` ที่ระดับบนของ body | shim ต้องแตก stream ให้ถูก |
| `invoke` | ได้ `.text`, `usage_metadata` `{input_tokens, output_tokens, total_tokens}` จาก `prompt_eval_count` / `eval_count` ของชิ้นสุดท้าย · `response_metadata` มี `model_provider: "ollama"`, `done_reason` | บท 007–008 |
| `think: true` + `message.thinking` | ได้ `additional_kwargs.reasoning_content` และ block `{type:"reasoning"}` ใน `contentBlocks` · `.text` ไม่รวมความคิด | บท 011 |
| `.stream()` | ได้ประมาณ 1 ชิ้นต่อบรรทัด NDJSON ที่มีข้อความ และอีก 2 ชิ้นที่ไม่มีข้อความ | บท 015 นับเฉพาะชิ้นที่ `.text` ไม่ว่าง |
| abort กลาง stream | throw `DOMException` ชื่อ `AbortError` | บท 015 |
| ชื่อโมเดลผิด | `ResponseError`, `status_code` 404, ข้อความ `model "x" not found, try pulling it first` | บท 012 |
| ต่อไม่ได้ | `TypeError: fetch failed` | บท 012 |
| **`invoke(q, { timeout })` หรือ `{ signal }`** | **ไม่ throw** ได้ข้อความครึ่งเดียวหรือ `""` | บท 013 สอนว่าต้องใช้ timeout กับ `.stream()` |
| `.stream(q, { timeout: 1 })` | throw `DOMException` ชื่อ `TimeoutError` | บท 013 |
| `maxRetries` ของ `ChatOllama` | ไม่มีผล (ไม่ผ่าน `AsyncCaller`) | บท 013 ใช้ `.withRetry()` · `ChatGoogle` ใช้ `maxRetries` ได้ |
| `.withRetry({ stopAfterAttempt, onFailedAttempt })` | ลองใหม่ได้จริง · ถ้า throw ใน `onFailedAttempt` จะหยุดทันที · `RunnableLambda` ที่ครั้งแรกใช้ `.stream(q, { timeout: 1 })` ได้ `ครั้งที่ 1: ล้มเหลว (TimeoutError)` แล้ว `ครั้งที่ 2: สำเร็จ` (ใช้เวลาประมาณ 1 วินาที) | บท 013 |
| `.batch(xs, { maxConcurrency: 2, callbacks })` | งานพร้อมกันสูงสุดได้ 2 จริง | บท 014 |
| `returnExceptions` | ต้องเป็น**อาร์กิวเมนต์ที่ 3**: `batch(xs, {}, { returnExceptions: true })` ถ้าใส่ในอาร์กิวเมนต์ที่ 2 โปรแกรมพัง | บท 014 |
| ชื่อ option ของ `ChatOllama` | ใช้ `numPredict` (ไม่มี `maxTokens`), `temperature`, `think?: boolean`, `baseUrl`, `headers` | บท 010–011 |
| ชื่อ option ของ `ChatGoogle` | `model`, `apiKey`, `maxOutputTokens`, `thinkingLevel` (`"minimal"\|"low"\|"medium"\|"high"`), `maxRetries` · `response_metadata.model_provider` เป็น `"google"` และมี `finishReason` | ไฟล์ `.google.ts` |
| `readline/promises` `rl.question()` เมื่อ input มาพร้อมกันหลายบรรทัด | **คำถามที่ 2 ไม่เคยได้คำตอบ** (บรรทัดหาย) | `ask()` อ่านผ่าน async iterator (ทดลองแล้วได้ครบทุกบรรทัด) |
| `stdin.pause()` หลังอ่าน | โปรแกรมจบเองแม้ stdin ยังเปิดอยู่ | `ask()` |
| opencode `deepseek-v4.1-flash` | ส่ง `reasoning_content` มาเสมอ · ส่ง `thinking: {type:"disabled"}` แล้วไม่คิด และ token ลดลง · `max_tokens: 5` ได้ content ว่าง `finish_reason: "length"` เพราะความคิดใช้ token ไปหมด | shim (Task 1) · README บท 010 |
| `checkNoHardcodedModels` | regex ``/\bmodel\s*:\s*["'`]/`` จับ `` model: `${...}` `` ด้วย | ชื่อโมเดลผิดในบท 012 ใช้ `env("OLLAMA_MODEL") + "-not-real"` |

## Review Focus

1. **จบแชทโดยไม่พิมพ์ "จบ"** เช่นกด Ctrl+D (Windows กด Ctrl+Z แล้ว Enter) หรือ input ที่ส่งมาหมดก่อน: แชทบอทต้องจบเองด้วย exit 0 ไม่วนถามซ้ำไม่รู้จบ และไม่ค้างหลังคำสั่งสุดท้าย → ทดสอบใน Task 5 (`EOF แล้วถามต่อก็ยังได้ null ไม่ค้าง`, `จบเองหลังถามครั้งสุดท้าย แม้ stdin ยังไม่ปิด`) และ Task 12 (เกณฑ์ `016 exercise-1` ที่ input ไม่มี "จบ")
2. **กด Enter โดยไม่พิมพ์อะไร** ในแชทบอท: ต้องถามใหม่โดยไม่ส่งข้อความว่างไปที่โมเดล (Gemini ไม่รับข้อความว่าง) และไม่นับเป็นหนึ่งตา → ทดสอบใน Task 12 (input ของ `016 example` มีบรรทัดว่าง เกณฑ์นับคำตอบได้ 2 และนับประวัติได้ 5)
3. **พิมพ์ไทยที่มีสระอำ วรรณยุกต์ และขึ้นบรรทัดแบบ Windows (CRLF):** `ask()` ต้องคืนข้อความเดิมทุกตัว ไม่มี `\r` ติดท้าย → ทดสอบใน Task 5 (`ภาษาไทยมีสระอำ วรรณยุกต์ และ CRLF จาก Windows ไม่เพี้ยน`)

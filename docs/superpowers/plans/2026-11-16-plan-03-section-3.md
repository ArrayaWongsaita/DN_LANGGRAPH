- **ภาษา:** README ข้อความที่พิมพ์ และคอมเมนต์ในบท เป็นภาษาไทย · ชื่อตัวแปร ฟังก์ชัน ไฟล์ และ commit เป็นภาษาอังกฤษ
- **ชื่อโมเดล:** ห้ามฝังในโค้ด อ่านจาก `.env` เท่านั้น
- **ข้ามระบบ:** คำสั่งของผู้เรียนต้องเหมือนกันบน macOS และ Windows PowerShell · สคริปต์เรียก child ด้วย `process.execPath` ไม่ผ่าน shell

- **สร้างโมเดล:** ใช้โค้ดชุดนี้ ส่วนที่ต่างได้มีแค่ option ที่บทนั้นสอน
  ```ts
  // .ollama.ts
  import { ChatOllama } from "@langchain/ollama";
  import { env, optionalEnv } from "../../src/lib/env";
  const apiKey = optionalEnv("OLLAMA_API_KEY");
  const model = new ChatOllama({
    model: env("OLLAMA_MODEL"),
    baseUrl: env("OLLAMA_BASE_URL"),
    headers: apiKey === undefined ? undefined : { Authorization: `Bearer ${apiKey}` },
  });
  // .google.ts
  import { ChatGoogle } from "@langchain/google";
  import { env } from "../../src/lib/env";
  const model = new ChatGoogle({ model: env("GOOGLE_MODEL"), apiKey: env("GOOGLE_API_KEY") });
  ```
  - ห้ามอ่าน `OLLAMA_NUM_CTX` และ `LLM_PROVIDER` · ห้ามใส่ `numCtx`
- **รูปไฟล์ของบท:**
  - หัวไฟล์เป็นคอมเมนต์ไทย 2–4 บรรทัด มีบรรทัด `// รัน: pnpm lesson NNN <ไฟล์>`
  - เขียน `export async function main(): Promise<void>`
  - ตัวอย่างแบ่งผลด้วยบรรทัด `--- ขั้นที่ 1: ... ---` และ `--- ขั้นที่ 2: ... ---`

- **guard ของแบบฝึก:**
  - ที่ให้เติมทุกจุดเป็นฟังก์ชันที่ตอนยังไม่เติมคืนค่าว่างตามชนิด (`undefined`, `""`, `[]`, `{}`) หรือคืนค่าที่รับเข้ามาเดิม
  - ก่อนเรียกโมเดลครั้งแรก `main` เรียกฟังก์ชันนั้นกับข้อมูลตัวอย่าง ถ้ายังได้ค่าว่าง พิมพ์ `👉 ยังไม่ได้เติม <ชื่อฟังก์ชัน> (ดูบรรทัดที่มี 👉)` แล้ว `return`
  - ห้ามใช้ `const x: T | undefined = undefined` เป็นที่เติม · async placeholder คืน `Promise.resolve(...)` (กฎ lint `require-await`)
